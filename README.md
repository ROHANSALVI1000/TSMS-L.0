TSMS L.0 – Student Management System

TSMS L.0 is an upgraded version of my original Student Management System, rebuilt using modern full-stack technologies. The project aims to provide a school management platform with separate functionalities for students, teachers, and the principal.

Features

Student

- View examination results
- View class timetable

Teacher

- Upload student examination results
- Add timetable information
- Access syllabus section

Principal

- Password-protected administration section
- Add, delete, and update teacher information
- View teacher salary, payment status, and assigned subjects

Tech Stack

- Frontend: React.js, JavaScript, HTML, CSS
- Backend: Python, FastAPI
- Database: PostgreSQL
- ORM: SQLAlchemy
- Authentication: JWT
- Password Hashing: pwdlib
- Database Migrations: Alembic (planned)
- Caching: Redis (planned)
- Environment Management: Python-dotenv
- Tools: Git, GitHub, VS Code
